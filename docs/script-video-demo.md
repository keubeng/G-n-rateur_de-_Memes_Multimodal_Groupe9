# Script — Vidéo de démonstration (3-5 min)

## 0:00 - 0:30 — Introduction
- Présenter rapidement le nom de l'app et son objectif
- Montrer l'écran d'accueil

## 0:30 - 1:30 — Démo Context Reader
- Coller un exemple de discussion
- Montrer le résultat généré par l'IA

## 1:30 - 2:30 — Démo Voice-to-Meme
- Enregistrer une note vocale en direct
- Montrer la transcription + le meme généré

## 2:30 - 3:30 — Démo Status Remixer (si prêt)
- Uploader une image depuis la galerie
- Montrer le texte ajouté par l'IA

## 3:30 - 4:00 — Bonus (si implémentés)
- Montrer rapidement la localisation culturelle (exemple avec expression camerounaise)
- Montrer le Share Intent si fonctionnel

## 4:00 - 4:30 — Conclusion
- Résumer les fonctionnalités couvertes
- Remercier
